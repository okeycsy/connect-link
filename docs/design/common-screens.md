# 공통 화면 기획 (4차 시안 기준)

- 작성일: 2026-10-13
- 상태: SHY 확인 대기 (남은 확인 사항은 맨 아래)
- 시안 페이지: [common-screens-mockup.html](./common-screens-mockup.html) (GitHub Pages가 켜져 있으면 `https://okeycsy.github.io/connect-link/docs/design/common-screens-mockup.html` 에서 열림)
- 요구사항 원본: Notion "요구사항/기능 명세"

이 문서는 네 업무 영역(계좌통합관리, 자동이체통합관리, 대출이동, CMS)이 함께 쓰는 공통 화면의 구조와 디자인 언어를 정리한 것이다. 목업의 기관·사람·번호는 모두 가짜 데이터다.

## 1. 공통 화면 범위

| 화면 | 담는 내용 | 근거 |
| --- | --- | --- |

## 2. 확정된 결정

| 항목 | 결정 | 비고 |
| --- | --- | --- |
| 화면 구조 | 왼쪽 업무 레일(64px) + 업무별 보조 메뉴 컬럼(176px) + 상단 전역 바 | SHY: 레일 + 보조 메뉴는 강점. 상단 가로 메뉴로 바꾸지 않는다 |
| 메인 화면 | "지금 할 일" 카드 대시보드 | 가장 급한 일 하나를 크게, 나머지는 작은 카드 |
| 목록 화면 | 필터 칩 + 데이터 그리드, 상세는 오른쪽 패널(모바일은 바텀 시트) | 연락처, 의견 요청, 기관 테스트, 일시중단 공통 |
| 로그인 | 하나의 화면. 이메일 도메인과 가입 정보로 소속 구분 | "결제원 / 기관" 선택 버튼 없음 |
| 메인색 | 채도를 조금 낮춘 비비드 블루 #3B6FDC. 상단 바·레일·로그인 패널의 배경으로 사용 | 금융결제원 CI 색은 쓰지 않는다 |
| 쓰지 않는 것 | 남색 크롬, 흰 면이 많은 중립 스타일, 무채색·인디고·틸 팔레트 | SHY가 2~3차에서 제외 |
| 디자인 언어 | 레이어드 블루 (아래 3절) | 4차 시안, 상장 전 소프트웨어 회사 수준을 목표 |
| '전체' 레일 | 운영·상황실·대외계처럼 전 업무를 보는 결제원 직원에게만 표시 | 확인 대기 |

### 결정 이력

1. 1차 (2026-10-13): A 워크벤치 / B 할 일 홈 / C 업무 워크스페이스 세 안 비교. SHY 선택: C 구조 + B 홈 + A 스타일, CI 색, 단일 로그인.
2. 2차: CI 파랑 적용. SHY가 CI 색 제외를 요청, 레퍼런스 팔레트 3종(잉크·인디고·딥 틸) 제시.
3. 3차: SHY 지시로 비비드 블루 + C안 레일·보조 메뉴 복귀, A 스타일 제외. 이어서 남색 제거, 채도 낮춘 블루를 배경 메인색으로.
4. 4차: "너무 단조롭다, 상장 앞둔 소프트웨어 회사 기준으로" 요청. 네 방향(프리미엄 핀테크, 제품 주도 SaaS, 한국 소비자용, 엔터프라이즈 데이터)을 만들어 비교한 뒤 핀테크 톤을 뼈대로 합쳐 레이어드 블루로 정리.

## 3. 디자인 언어: 레이어드 블루

파랑 하나를 네 겹으로 쌓는다. 색은 파랑 계열과 마감 전용 앰버, 정상 전용 민트까지만 쓰고, 숫자는 전용 서체로 한글 본문과 질감을 나눈다. 크롬이 가장 어둡게 내려가는 지점도 #2B55C0으로 남색이 아닌 진한 파랑에 머문다.

### 깊이 4층

| 층 | 요소 | 레시피 |
| --- | --- | --- |
| 0 크롬 | 상단 바, 레일, 로그인 패널, 홈 밴드 | `linear-gradient(180deg, #3B6FDC, #3464CC 50%, #2B55C0)` + 좌상단 radial 글로우(#5B8BF0, 50%) + SVG feTurbulence 그레인(알파 .07). 레일은 rgba(15,35,95,.12) 스크림으로 한 단계 깊게 |
| 1 프로스트·시트 | 보조 메뉴, 본문 영역 | 보조 메뉴 rgba(255,255,255,.86) + blur 12px. 본문은 #F3F6FC 시트가 radius 14로 크롬 안에 끼워짐 |
| 2 카드 | 카드, 폼, 표 본문 | #FFFFFF, 1px #D8E1F3, radius 12, 그림자 `0 1px 2px rgba(27,42,74,.06), 0 12px 28px -18px rgba(59,111,220,.45)`. 흰색은 여기에만 |
| 3 글래스 | 홈 밴드 위 KPI 타일 | rgba(255,255,255,.14) + 1px rgba(255,255,255,.28) + blur 8px + 상단 1px 하이라이트. backdrop-filter 미지원이면 반투명만 유지 |

### 시그니처 요소

1. 파란 시트: 본문이 radius 14의 시트처럼 크롬 안에 끼워져 모서리 밖으로 그라데이션이 비친다.
2. 글래스 KPI 타일: 홈 첫 줄, 파란 밴드 위 반투명 타일 네 개. 숫자 전용 서체, 앰버 진행 헤어라인 또는 민트 스파크라인.
3. 앰버 마감 마크: 난색은 마감과 재확인 필요에만.
4. 링 게이지와 업무별 스택 바: 정기 변경 진행률은 링, 업무별 완료 수는 파랑 네 단계로 쌓은 바.
5. 레일 토큰과 기관 모노그램: 업무는 둥근 사각 토큰, 기관은 두 글자 모노그램 타일. 레일, 표, 상세 패널에 반복.
6. 키캡과 헤일로 점: Ctrl K 키캡, 상태 점은 8px 점 + 연한 외곽 링.

### 글꼴, 아이콘, 모션

- 본문·UI: Pretendard Variable (OFL, npm `pretendard` 번들). 숫자·라틴: Geist (OFL). 식별자·키캡: Geist Mono. 스택을 `Geist, Pretendard Variable`로 두면 숫자만 Geist로 떨어진다. (Geist 도입 여부는 확인 대기)
- 크기 11 / 12 / 13 / 14 / 16 / 20 / 24 / 32px. 한글 `word-break: keep-all`, 숫자 `font-variant-numeric: tabular-nums`.
- 아이콘: Tabler Icons (Mantine 기본 짝, 번들).
- 모션: 160~240ms, `cubic-bezier(.2,.8,.2,1)`, 튕김 없음. 레일 토큰 180ms 슬라이드, 보조 메뉴 200ms 크로스페이드, 링 게이지 첫 로딩 1회 600ms, 상세 패널 240ms. `prefers-reduced-motion`에서는 투명도 전환만.
- 런타임에 CDN이나 외부 폰트를 쓰지 않는다. 시안 HTML만 Google Fonts를 대신 썼다.

| 방향 | 요지 | 참고 |

레이어드 블루는 프리미엄 핀테크 톤을 뼈대로 하고 위 세 방향에서 키캡, 모노그램, 연결 그래프, 카피 톤을 가져왔다.

## 6. 남은 확인 사항

1. '전체' 레일을 전 업무 담당 결제원 직원에게만 보이게 하는 것이 맞는지.
2. 숫자 서체 Geist를 Pretendard와 함께 쓸지, Pretendard 하나로 갈지 (두 서체면 번들 약 100KB 증가).
3. 로고: 시안의 "KFTC" 상자는 자리표시. 연결고리 전용 로고가 생기면 교체.
