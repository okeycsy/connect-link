# frontend/CLAUDE.md — 디자인 시스템 (B안 메신저형)

프론트 화면을 만들거나 고칠 때 이 문서를 따른다. 루트 `CLAUDE.md` 7절(프론트 규칙)과 함께 읽고, 화면 모양에 관해서는 이 문서가 우선한다.
여기 없는 모양이 필요하면 기존 토큰과 컴포넌트를 조합해서 만들고, 새 토큰이 필요하면 이 문서와 `src/app/theme.ts` 를 같은 커밋에서 함께 고친다. 규칙 자체를 바꿔야 할 것 같으면 사용자에게 먼저 묻는다.

- **출처**: 디자인 시안 "연결고리 포털 디자인 안"의 **B안 · 메신저형 포털** (2026-10-15, SHY 선택). 슬랙·매터모스트처럼 업무 레일 + 사이드바 + 본문 구조에, 밝은 회색 바탕·클레이 메인색·파스텔 번짐을 쓴다.
- **대체한 것**: `docs/design/common-screens.md` 3절 "레이어드 네이비"(남색 크롬, 글래스 타일)는 더 이상 쓰지 않는다. 그 문서의 화면 범위와 구조 결정(레일 + 보조 메뉴, 홈 카드 대시보드, 목록 + 오른쪽 패널)은 그대로 유효하다.
- **기준 파일**: 색·글꼴·radius 값은 `src/app/theme.ts`(Mantine 테마)와 `src/app/global.css`(`--cl-*` CSS 변수) 두 곳에만 있다.

## 1. 다섯 가지 원칙

1. **바탕은 밝은 회색, 일하는 면은 흰색.** 페이지·사이드바는 `page`(#F8F8F9), 본문과 카드는 흰색. 어두운 크롬(남색 상단 바 등)은 쓰지 않는다.
2. **유채색은 의미가 있을 때만.** 메인 `clay` 는 "누를 수 있음·지금 여기"(버튼, 링크, 활성 메뉴), `sky`·`amber`·`red` 는 상태에만 쓴다. 장식에 색을 쓰는 곳은 파스텔 번짐 하나뿐이다.
3. **둥글고 부드럽게.** 버튼은 알약, 카드는 radius 24, 목록 한 줄은 14, 메뉴 한 줄은 8. 각진 모서리와 굵은 그림자는 쓰지 않는다.
4. **파스텔 번짐은 정해진 곳에만.** 상단 바 오른쪽, 사이드바 아래, 홈 머리, 로그인 배경(시안 랜딩과 똑같이). 다른 화면에 번짐을 늘리지 않는다.
5. **hex 를 화면 코드에 쓰지 않는다.** TSX 에서는 Mantine 색 이름(`color="sky"`, `c="dimmed"`), CSS 모듈에서는 `var(--mantine-color-clay-6)` 이나 `var(--cl-line)` 만 쓴다.

## 3. 글꼴과 글자 크기

- 지금 글꼴은 **Pretendard Variable**(npm `pretendard` 번들)이다. 시안의 IBM Plex Sans KR 은 따르지 않는다(SHY 결정).
- **글꼴은 `src/app/fonts.css` 한 곳에서만 정한다.** 앱 전체(Mantine 테마의 `fontFamily`, 제목, 숫자)가 CSS 변수 `--cl-font-sans`(고정폭은 `--cl-font-mono`) 하나를 쓴다. `theme.ts`, CSS 모듈, 컴포넌트에서 글꼴 이름을 직접 쓰지 않는다(`ff="monospace"` 는 Mantine 이 `--cl-font-mono` 로 바꿔 준다).
- **글꼴 바꾸는 방법**(사용자가 글꼴 파일을 받아 오면):
  1. woff2 파일을 `src/assets/fonts/` 에 둔다. 빌드 때 app.jar 에 함께 들어가므로 외부 URL 이 생기지 않는다.
  2. `fonts.css` 의 `@font-face` 예시 주석을 풀고 이름·파일명·굵기 범위를 맞춘다.
  3. `--cl-font-sans` 맨 앞에 새 이름을 넣는다. Pretendard 를 더 쓰지 않으면 `@import 'pretendard/…'` 줄을 지운다.
  4. `./gradlew build` 후 캡처로 줄바꿈·굵기를 확인한다. 다른 파일은 고치지 않는다.
- npm 글꼴 패키지를 새로 넣는 방식은 의존성 추가라 사용자 확인이 필요하다(루트 CLAUDE.md 2-5). 파일을 직접 두는 방식은 확인 없이 해도 된다.
- 숫자는 `font-variant-numeric: tabular-nums`(표의 번호·날짜·건수).

| 용도                 | 크기 / 굵기  | Mantine                     |
| -------------------- | ------------ | --------------------------- |
| 홈 인사말            | 34 / 700     | `<Title order={1}>`         |
| 화면 제목(머리 막대) | 20 / 700     | `PageHeader` 가 처리        |
| 카드 제목            | 17~20 / 700  | `<Text fw={700} size="xl">` |
| 본문                 | 15           | `size="lg"`                 |
| 표·목록 기본         | 14           | `size="md"`                 |
| 메타·라벨·배지       | 13 / 500~600 | `size="sm"`                 |
| 작은 보조            | 12           | `size="xs"`                 |

테마 `fontSizes` 는 xs 12, sm 13, md 14, lg 15, xl 17 이다.

## 4. 모양: radius, 간격, 그림자

| 토큰        | 값  | 쓰는 곳                                                 |
| ----------- | --- | ------------------------------------------------------- |
| `radius.xs` | 4   | 날짜·분류 태그                                          |
| `radius.sm` | 8   | 사이드바 한 줄, 사용자 아바타, 팔레트 항목              |
| `radius.md` | 12  | 레일 토큰, 기본값                                       |
| `radius.lg` | 14  | 입력 칸, 목록 한 줄, 메뉴·팝오버                        |
| `radius.xl` | 24  | 카드, Paper, Modal, Drawer 바깥 모서리, 버튼·배지(알약) |
| (직접) 32   |     | 로그인 카드                                             |

- 간격은 Mantine spacing 을 쓰고, 묶음 사이 `gap="lg"`, 카드 안 `gap="sm"`, 목록 한 줄 사이 8px 이다.
- 그림자는 `shadow="card"`(`0 24px 48px -28px` 클레이 톤) 하나뿐이고 떠 있는 것(Menu, Popover, 로그인 카드)에만 쓴다. 본문 카드는 그림자 없이 테두리 또는 바탕 대비로 구분한다.

### 5.1 휴대폰 폭(모바일 웹)

별도 앱 없이 같은 화면을 휴대폰 브라우저에서 쓴다(2026-10-20 SHY 요청). 기준 폭은 Mantine `sm`(48em = 768px)이고, 그보다 좁을 때만 아래처럼 바뀐다. 태블릿·데스크톱 모양은 그대로다.

- **앱 셸**: 레일 + 사이드바는 접어 두고 상단 바 왼쪽 메뉴 버튼(`Burger`, "메뉴 열기")으로 화면 전체에 연다. 메뉴를 고르거나 주소가 바뀌면 닫힌다. 사이드바 한 줄은 높이 44(손가락 크기).
- **상단 바**: 로고 높이 32, 가운데 검색 칸은 돋보기 아이콘 버튼으로 바뀐다(같은 검색 창을 연다). 사용자 이름은 숨기고 아바타만 둔다.
- **본문 여백**: `--cl-page-gutter` 가 16 으로 줄어든다(머리 막대·홈도 따라간다). 홈 인사말은 26.
- **머리 막대**: 제목 옆 상태 배지와 오른쪽 동작 버튼이 넘치면 다음 줄로 내려간다.
- **표 → 카드**: 목록 표는 `shared/list/ResponsiveTable.module.css` 의 `stack` 클래스를 `<Table>` 에 붙이고 칸마다 `data-label="열 이름"` 을 단다. 휴대폰 폭에서 머리 줄이 숨고 행 하나가 카드 한 장(radius 14, 1px line)이 되어 "열 이름 | 값" 이 줄마다 쌓인다. 첫 칸(제목)은 `data-label` 없이 둔다. 기관별 묶음 머리 행은 `data-group` 을 단다. 열이 아주 많은 표(의견 취합표)는 카드로 바꾸지 않고 `Table.ScrollContainer` 로 옆으로 민다.
- **상세 패널·모달**: `DetailDrawer`·Modal 은 Mantine 이 화면 폭에 맞춰 준다. 따로 고치지 않는다.
- 새 화면은 8절 4번과 함께 390px 폭에서도 옆으로 밀리지 않는지 본다(E2E `tests/mobile.spec.ts`).

## 6. 컴포넌트 규칙

### 화면 머리 막대 — `shared/PageHeader`

- 홈을 뺀 **모든 화면의 첫 요소**다. 제목(h1, 20px) + 설명(dimmed) 왼쪽, `status`(배지) 제목 옆, `actions` 오른쪽.
- 본문 여백을 거슬러 위·양옆 끝까지 붙는 흰 막대이고 아래 1px 선이 있다. 화면 쪽에서 따로 제목을 만들지 않는다.
- 감싸는 요소는 `<Stack gap="md">` 이고 머리 막대가 첫 자식이어야 한다(여백 계산이 그 전제다).

### 버튼

- 기본은 알약(radius xl), 굵기 600. 한 화면(머리 막대 기준)에 **채움(`filled`) 버튼은 하나**, 나머지는 `light`(clay-1 바탕) 또는 `outline`.
- 위험한 동작은 `color="red"` + `variant="light"`, 확인 모달에서만 채움 빨강을 쓴다.

### 카드

- **흰 본문 위**: 기본 `<Card>`(테두리 1px `line`, radius 24, 그림자 없음).
- **page 바탕 위(홈)**: 테두리 없는 흰 면(`HomeCardView` 의 `.card`). 왼쪽 굵은 테두리는 쓰지 않는다.

### 홈 배치 (`features/home/pages/HomePage.tsx`)

- **결제원 담당자**: 날짜 태그 + 인사말 → [왼쪽 5/12 가입 승인 대기(없으면 회신 대기 의견 요청) | 오른쪽 7/12 다가오는 일시중단] → 나머지 카드(장 수만큼 열을 나눠 한 줄을 채운다, 최대 3열). 윗줄 두 칸은 `tall` 로 높이를 맞추고, 둘 중 하나만 있으면 한 줄을 다 쓴다.
- **기관 담당자**: 일시중단 카드가 없어 윗줄을 두지 않고, 요청받은 일 카드(연락처 변경·확인 요청, 회신할 의견 요청, 요청받은 기관 테스트, 우리 기관을 부른 대화)를 한 줄에 두 장씩(휴대폰은 한 장) 놓으며 같은 줄 카드 높이를 맞춘다(`tall`). 줄마다 기관이 할 일 단계(예: "미작성", "임시저장", "결과 미등록 2건", "테스트데이터 회신 2026-10-28까지")를 부제로 보인다. SHY 요청(2026-10-24).
- 확인이 필요한 담당자 카드는 따로 두지 않는다(6개월 확인은 로그인 뒤 확인 창과 기관 홈의 연락처 변경·확인 요청 카드가 맡는다). 임박·초과 글자 배지는 카드 머리에 두지 않는다(기한 배지 색은 그대로).

- 카드 안은 제목·배지, 짧은 요약 한 줄(예: "확정 전 2건"), 할 일 줄(일시중단 밖 카드는 3줄까지)만 둔다. 숫자 줄·진행 막대·진행률 원은 홈에 두지 않고 "모두 보기" 화면에서 본다. SHY 요청(2026-10-24).
- 최근 알림은 홈에 두지 않는다. 상단 바 알림 벨(`NotificationBell`)과 알림 센터에서 본다.

- 자리 배치는 `MAIN_KEY`·`SIDE_CANDIDATES` 상수가 정한다. 카드를 옮길 때는 이 상수만 고친다.

## 7. 하지 말 것

- 남색 크롬, 글래스(반투명 + blur) 타일, 그라데이션 버튼, 왼쪽 굵은 테두리 카드. (blur 는 로그인 배경 번짐에만 쓴다.)
- 색 이름 추가(`blue`, `green`, `teal`, `navy` …), TSX 의 hex·rgb, 인라인 `style` 로 색 지정.
- 이모지 아이콘. 아이콘은 `@tabler/icons-react`(선 굵기 1.6~1.8, 18~20px)만 쓴다.
- 외부 웹폰트·CDN(루트 CLAUDE.md 2-2).
- 회색 글자를 gray-5 이하로 더 연하게(대비 4.5:1 미만) 쓰는 것. 보조 글자는 `dimmed`(gray-6)까지다.
- 다크 모드 전용 스타일. 지금은 라이트 모드만 지원한다(`defaultColorScheme="light"`).
